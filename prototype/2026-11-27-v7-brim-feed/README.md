# V7 brim-full capsule feed trials

The three-track module is sized for 21.75 mm long × 7.75 mm diameter capsules and fits the six existing V7 station positions. In two simulated brim-full loads (63 and 75 capsules), it released one capsule on each of the first three 60° steps and missed the fourth. **Hold the six-module print.** The simulation assumed a 0.10 N·m shaft torque limit.
